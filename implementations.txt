How to apply tenant scope + RBAC in future routes

Example pattern for any protected resource:

// inside a route/controller
import { asObjectId } from "../utils/auth";
import { requireAuth, requireRoles } from "../middlewares/auth";
// e.g. in a tickets router
router.get("/", requireAuth, requireRoles("OWNER","ADMIN","AGENT"), async (req,res) => {
  const auth = (req as any).auth as { tid: string };
  const tenantId = asObjectId(auth.tid);
  const tickets = await Ticket.find({ tenantId }).limit(20).lean();
  res.json({ data: tickets });
});

4) Roles (consolidated)

Use these across the app:

export type Role = "OWNER" | "ADMIN" | "AGENT" | "BILLING" | "READONLY" | "INTEGRATION";


OWNER: everything + billing + user mgmt

ADMIN: everything except ownership transfer

AGENT: tickets full, limited customers

BILLING: subscriptions/invoices

READONLY: read everything; no writes

INTEGRATION: API keys for external systems

Your requireRoles("...") middleware already supports this set.

In controllers (e.g., on reply), call:
;(global as any).notifyTicket(tenantId, ticketId, { event:"ticket.replied", ... })
