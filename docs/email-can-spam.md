# CAN-SPAM Compliance

## Requirements Met
- [x] Emails identify sender (From address)
- [x] Subject lines not deceptive
- [x] Physical address included (configure in branding)
- [x] Opt-out mechanism (List-Unsubscribe header)
- [x] Honor opt-outs within 10 days
- [x] Hard bounce suppression (emailTracking webhook)

## Transactional Exemptions
Transactional emails (verification, password reset, ticket notifications) are exempt from CAN-SPAM opt-out requirements.
